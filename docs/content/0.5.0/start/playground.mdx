The local playground deliberately supports a limited registered vocabulary and bundled resources. Use the complete application samples for native services and custom code.

## Try a small change and check the result

1. Run the button example, then change `Content` to “Save changes” and run it again.
2. Set `IsEnabled="False"` and confirm the control no longer activates.
3. In the Grid example, switch between `Auto,*` and `*,*` columns and narrow the preview.
4. Introduce an unknown property to inspect its error, then reset the example.

This runner supplies a theme and supported type registration. A model binding such as `{Binding SaveCommand}` still needs an application model; typing it here does not create one. Follow the [commands guide]({{BASE}}/guides/commands/) for that integration.
